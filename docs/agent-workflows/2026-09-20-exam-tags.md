# Inhaltliche Tags für bestehende Online-Prüfungen

## Inhaltliche Zuordnung

Jede Ausarbeitung vollständig lesen. Tags erfassen Rechtsgebiet, erkennbare praktische Aufgabenform und die tatsächlich ausgeführten Schwerpunkte. Ein verneinter Anspruch kann ein Schwerpunkt sein; bloß erwähnte Normen und unausgeführte Gliederungspunkte reichen nicht. Ähnliche Themen erhalten dieselben Begriffe. Unsichere Aufgabenformen nicht aus Dateinamen ableiten.

Die geprüften Zuordnungen mit Textbelegen, Vorher-/Nachher-Sicherung und SQL bleiben außerhalb des App-Repositorys im privaten Importverzeichnis. Bestehende Entwürfe, Revisionen, Abgaben, Notizen und andere Kontostände werden nicht geändert. Der produktive Schreibvorgang ist auf das aufgelöste Konto und den gesicherten Snapshot-Hash begrenzt; bei einer zwischenzeitlichen Änderung bricht er ab.

## Bereits vorhandener Browserstand

Der bisherige Import-Ladeweg ergänzte nur fehlende Prüfungen. Ein vorhandener Browserstand hätte nachträglich vergebene Tags nicht übernommen und beim Sichern wieder entfernen können.

Der Browser-Snapshot unterstützt dafür optionale Metadaten je Prüfung:

```json
{
  "tagImport": {
    "schemaVersion": 1,
    "revision": 1,
    "tags": ["Zivilrecht", "Vollstreckungsabwehrklage"]
  }
}
```

`tags` enthält die bewusst importierte Ergänzung. Die regulären Prüfungstags sowie `tables.exams.tags_json`, `tables.tags` und `tables.exam_tags` müssen damit konsistent geschrieben werden. Der Marker wird in `browserStore` aufbewahrt; er ändert weder das SQLite-Schema noch das `.jura`-Paketformat. Bestehende Daten ohne Marker funktionieren unverändert.

Beim Laden nach Seitenstart und vor dem Hochladen ergänzt die App markierte Tags vorhandener Prüfungen einmalig. Sie übernimmt nur Tags, die im aktuellen Online-Stand noch vorhanden sind, und erhält eigene lokale Tags. Prüfungstext und andere Metadaten bleiben lokal erhalten. Gleiche oder ältere Importrevisionen werden nicht erneut angewendet, damit bewusst entfernte Tags entfernt bleiben. Unbekannte Schemata, ungültige Revisionen und fremde Besitzer werden ignoriert. Eine spätere neue Importrevision benötigt eine neue inhaltliche und konfliktbezogene Prüfung; eine normale manuelle Tag-Änderung erhöht den Marker nicht.

Bereits geöffnete Seiten müssen für den neuen Ladeweg neu geladen werden. Eine allgemeine Konfliktlösung für parallele Änderungen derselben Prüfung auf mehreren Geräten ist nicht Teil dieser Ergänzung.
